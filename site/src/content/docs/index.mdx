## What you get

<CardGrid stagger>
  <Card title="One IR, many codecs" icon="puzzle">
    Application code speaks a version-agnostic superset. Per-revision codecs lift
    wire messages into the IR and lower them back out for whatever version was
    negotiated. No revision forks in your code.
  </Card>
  <Card title="Runtime feature gating" icon="seti:config">
    A pure domain function turns the negotiated protocol version, client
    capabilities, server capabilities, and transport into a FeatureProfile.
    Every feature-specific code path checks the profile. Nothing is silently
    dropped.
  </Card>
  <Card title="Every transport the spec has defined" icon="seti:default">
    stdio, legacy HTTP plus SSE (2024-11-05), Streamable HTTP (stateful), and
    the 2026-07-28 stateless lifecycle. The CLI is a Swiss-army knife on top:
    bridge, probe, inspect, record, replay.
  </Card>
  <Card title="Spec-exact, conformance-verified" icon="approve-check">
    The vendored schema.json for every revision is the single source of truth.
    Conformance suites run on every revision, every commit. No hand-remembered
    wire shapes.
  </Card>
  <Card title="A* schema support" icon="rocket">
    A2A and ACP ride the same internal model as MCP. The A*-prefixed
    protocols (A2A, ACP) get their own vendored schemas and codecs, so the
    bridge translates between protocols without re-implementing your
    application.
  </Card>
</CardGrid>
