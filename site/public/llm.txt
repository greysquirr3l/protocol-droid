# protocol-droid

> A Rust MCP toolkit that speaks every published spec revision at once
> (2024-11-05 through 2026-07-28, plus draft) and bridges to the A*
> protocols (A2A, ACP) through the same canonical model. One internal
> representation behind per-revision codecs, runtime feature gating,
> every transport the spec has ever defined.

A Rust crate (`protocol-droid`) for building MCP servers and clients
that speak every published revision at once, and bridges to A2A and
ACP through the same internal model. Schema types for every revision
coexist; a single binary serves stdio, HTTP+SSE, and Streamable HTTP.
The CLI bridges between protocol revisions, probes servers, records
and replays sessions, and runs the conformance suite.
